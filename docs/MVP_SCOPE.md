# MVP scope

## In V1

### Low-friction entry

- anonymous New Show / Quick Timer;
- 7-day unclaimed lifecycle;
- claim to account;
- expiry warnings and safe cleanup.

### Queue/show core

- Show + one or more Queues;
- universal Queue Items;
- notes;
- Groups;
- tags;
- visibility/audiences;
- active/inactive/skip behavior;
- drag/drop and duplication;
- parallel Queues;
- relative item relationships.

### Timers/scheduling

- countdown;
- count-up/overtime;
- warning/critical states;
- pause/resume/stop/end;
- time adjustment;
- multiple running timers;
- manual/scheduled/previous-end/external-ready start modes;
- Strict and Sliding;
- fixed anchors;
- ahead/on-time/behind;
- visible inheritance/overrides.

### Control/presentation

- Master View;
- Operator View;
- Board presets;
- professional constrained customization;
- ad-hoc messages;
- realtime state;
- short-outage Board resilience.

### Event/device/access

- Events;
- optional Rooms/Areas;
- Event Dashboard;
- QR/share;
- persistent Devices and pairing;
- extensible permission system;
- locks + Request Unlock + emergency override.

### External

- basic authenticated/scoped HTTP API.

## Explicitly later

- OSC;
- Companion integration;
- QLab integration;
- MIDI;
- Local Agent;
- advanced outbound Action engine;
- unlimited free-form Board Designer;
- automatic schedule recovery;
- elaborate analytics/history;
- complex custom role editor;
- advanced Admin Portal;
- billing/licensing implementation.

## Scope rule

Do not promote a Later feature into V1 because it is easy to implement. V1 quality of the timer/show/realtime core takes precedence over feature count.
