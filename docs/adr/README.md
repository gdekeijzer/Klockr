# Architecture Decision Records

ADRs capture decisions that materially affect implementation or long-term structure.

Status vocabulary: Proposed, Accepted, Superseded, Deprecated.

If a future decision changes an Accepted ADR, add a new ADR and mark the old one Superseded rather than rewriting history.
